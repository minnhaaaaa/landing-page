# Landing Page
A landing page built from scratch using HTML and CSS Flexbox, as part of The Odin Project curriculum.
## About
This project was built by replicating a reference image using only HTML and CSS with no extra frameworks or libraries. 

The project holds a special place for me. In a world where everyone reaches for AI at the first sign of a challenge, I built this entirely on my own with no AI. Just me, my brain, and a reference image to replicate.
Every layout, every spacing decision, every flexbox property was figured out through my own thinking and problem solving. And when it finally came together, that feeling was mine alone.
Safe to say that I am incredibly proud of this one!

## What I Learnt
* Structuring semantic HTML for a multi-section page
* Using CSS Flexbox for layout and alignment
* Applying CSS Box Model techniques
* Working with Google Fonts
* Translating a visual design reference into real code

## Built With
* HTML5
* CSS3 (Flexbox)

## Notes
The page uses placeholder text and images as this is a layout and styling exercise rather than a real product site.
